SEBASTIAN TAPIA - SIMPLE PORTFOLIO WEBSITE

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the folder named Sebastian_Tapia_Simple_Portfolio.
3. Double-click index.html to open the website in your browser.

HOW TO EDIT:
- index.html: Change your name, About Me text, skills, projects, and contact details.
- style.css: Change colors, fonts, spacing, and the design.
- script.js: Change the welcome message or add simple interactions.

IMPORTANT:
The email address is a sample. Replace it with your own email address.
You can edit these files using Visual Studio Code or another text editor.
